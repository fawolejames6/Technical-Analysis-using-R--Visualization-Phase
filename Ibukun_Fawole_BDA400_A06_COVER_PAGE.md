### Project Description

This project involves developing an interactive R Shiny dashboard that retrieves historical stock data from Yahoo Finance using `quantmod`,
displays price movements through line, area, or candlestick charts, and allows users to enable or disable technical indicators such as Moving Averages,
RSI, and MACD.

### Repository Link:https://github.com/fawolejames6/Technical-Analysis-using-R--Visualization-Phase

### How to Run
1. Open `portfolio_dashboard.R` in R / RStudio (or Posit Cloud).
2. Install required packages if needed: `shiny`, `ggplot2`, `quantmod`, `TTR`, `scales`.
3. Click "Run App" or run `shiny::runApp("portfolio_dashboard.R")`.
4. Enter a stock symbol, choose a date range and chart type, select indicators,
   adjust the MA periods, and click "Update Dashboard".
