# Technical-Analysis-using-R--Visualization-Phase
This project is an interactive portfolio dashboard built with R Shiny. It uses the quantmod package to pull historical stock data from Yahoo Finance, and users can view price movements as line, area, or candlestick charts. Moving Averages, the Relative Strength Index (RSI), and the Moving Average Convergence Divergence (MACD) are available as optional technical indicators, and each one can be switched on or off.

The app also has an adjustable Moving Average (MA) Crossover trading rule that produces Buy, Sell, and Hold signals. The signals are marked right on the price chart, and a summary table lists the latest ones so they can be checked at a glance.
